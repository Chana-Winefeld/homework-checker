# 🎓 Java Homework Grader

כלי אוטומטי המיועד למורים למדעי המחשב, המאפשר בדיקה מהירה ויעילה של הגשות תלמידים בשפת Java. הכלי סורק תיקיות הגשה ומפיק דו"ח אקסל מעודכן בזמן אמת.

## 📋 תיאור הפרויקט
הכלי נבנה כדי לחסוך זמן יקר למורים. במקום לעבור תלמיד-תלמיד, המורה פשוט מזינה את נתיב התיקייה ואת שם התרגיל, והמערכת מבצעת את הסריקה באופן אוטומטי.

### איך זה עובד?
1. **ניתוב:** המורה בוחרת את תיקיית האב המכילה את תיקיות התלמידים.
2. **חיפוש:** המערכת סורקת כל תיקיית תלמיד בנפרד.
3. **אימות:** הכלי מחפש קובץ `.java` ששמו תואם בדיוק לשם התרגיל המבוקש.
4. **דיווח:** המערכת מעדכנת קובץ אקסל קיים (או יוצרת חדש) ומסמנת `V` להגשה תקינה או `X` לחסרה.

## ✨ תכונות עיקריות
- **חיסכון בזמן:** בדיקת כיתה שלמה תוך שניות.
- **עדכון דינמי:** קובץ האקסל מתרענן ומתעדכן במקום ליצור קבצים כפולים.
- **דיוק:** בדיקה מבוססת שמות קבצים וסיומות תקניות.
- **ממשק פשוט:** מותאם לשימוש קל ומהיר למורה.
